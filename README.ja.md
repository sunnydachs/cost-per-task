# cost-per-task

AIに仕事を1件終わらせるのに実際にいくらかかるか(試行回数・トークン・待ち時間)を測ります。リクエスト単価ではなく、**完了1件あたりのコスト**です。

[English](README.md) | [日本語](README.ja.md)

トークン単価は「1リクエストいくら」を教えてくれるだけです。「仕事1件を終わらせるのにいくらかかったか」は教えてくれません。失敗した試行、リトライ、そして待つ時間。その比率("cost per successful task")が、安いモデル+リトライとexpensiveなモデル+1発が完了のどちらが勝つかを決めます。

このリポジトリの主題は**手順**であり、どのモデルについての判定でもありません。

1. 出力をコードで判定できるタスクを選ぶ
2. 検証器を書く
3. 同じタスク・同じプロンプトを各モデルアームで最大N回まで回す
4. 試行ごとに記録する(トークン・経過時間・合否)
5. 集計する: 成功1件あたりトークン、リトライ税(試行÷成功)、機械時間

## 必要なもの

- Python 3.11以上
- OpenAI互換のchat-completionsエンドポイントへのAPIキー
- ランタイム依存なし(標準ライブラリのみ)

## 使い方

```bash
export NVIDIA_API_KEY=...            # または --api-key-env MY_KEY

# 1アーム
python cost_per_task.py --model A=vendor/model-one

# 2アーム(同じタスク、同じプロンプト)
python cost_per_task.py --model A=vendor/model-one --model B=vendor/model-two

# タスクを選ぶ・試行回数を増やす・エンドポイントを指定
python cost_per_task.py --model A=vendor/model-one \
    --tasks csv_convert doc_extract \
    --max-attempts 5 \
    --base-url https://my-endpoint.example/v1 \
    --out-dir ./run1
```

出力:

- `results.json` — 試行ごとの記録(トークン・遅延・合否・生レスポンス)
- `report.md` — タスク別・アーム別の集計

実行は**再開可能**です。同じコマンドを再実行すると、成功済みの組み合わせはスキップし、記録済みの試行を繰り返しません。最初からやり直すには `results.json` を削除してください。

## タスクと検証器

| タスク | 依頼内容 | PASSの判定方法 |
|---|---|---|
| `csv_convert` | 汚いCSVの正規化(列名の変換・メールの小文字化・国名の変換・メール無し行の除外) | ヘッダーと行集合を期待値と比較 |
| `py_bugfix` | `chunk()`の境界値バグを修正 | 返されたファイルをディスクに書き、テストファイルを**実行** |
| `json_build` | 散文から注文JSONを作る | キー・値・計算した合計を比較 |
| `doc_extract` | ノイズ入り請求書から5項目を抽出 | 値を比較。前の月分の未払が合計に混ざらないことも確認 |

LLMが判定することも、人間が判定することもありません。検証器が間違っていれば計測も間違ります。だから検証器には自前のテストがあります(`tests/test_verifiers.py`)。

## 数字の読み方

- **成功1件あたりトークン** — 最終的に成功したタスクに使った合計トークン。比較の基準になる数字です。
- **リトライ税** — 試行回数÷成功数。1.0なら全タスクが一発通過、2.0なら平均2回試行しています。
- **失敗タスクの消費込み** — 同じ比率ですが、失敗したタスクの消費も数えます。請求書に載る数字です。
- **合計秒(機械時間)** — 実行全体の経過時間。実額が見えないとき、実際に効いてくる軸はこれです。

通信エラー(HTTP 429/503、タイムアウト)は1試行の中でリトライされ、試行回数には数えません。検証器による失敗だけが試行回数に数えられます。いずれも `transport_errors` に記録されます。

## 制限

- タスク4件・単一言語・アーム2つ: モデル 一般化には小さすぎます
- 実額はプロバイダが教えてくれなければ不明です。このツールはトークンと経過時間だけを出します。価格は作りません
- リトライは同じプロンプトの繰り返しです。検証器のエラーをモデルに返していません(naive リトライの計測)
- 人間のレビュー時間は測っていません。観測製品も記録していません

## プライバシー

APIキーは環境変数から読み、ディスクには書きません。プロンプトとレスポンスは指定したエンドポイントにだけ送られます。`results.json` には生のレスポンスが入るので、コミットしないでください(gitignore済み)。
